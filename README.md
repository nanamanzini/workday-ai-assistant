# AI-Productivity-Assistant## Project OverviewAI Workplace Productivity Assistant is a modern, responsive web application designed to help professionals complete common workplace tasks more efficiently. It brings email writing, research support, and workplace chat into one simple dashboard.The interface uses a clean, professional light-grey, white, and dark-charcoal colour palette and adapts to desktop and mobile screens.## Features ImplementedThe project is designed to include the following features.
