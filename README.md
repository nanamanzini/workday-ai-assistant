# Workday AI Assistant

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant using React, Tailwind CSS, and a clean light-grey, white, and dark-charcoal theme.



Create a professional dashboard with sidebar navigation and three working tools:



1. Smart Email Generator: Generate personalised professional emails from user instructions, with Formal, Friendly, and Persuasive tones. Allow users to edit and copy results.

2. AI Research Assistant: Accept topics, pasted articles, and website URLs. Summarise content and provide key insights and practical recommendations. Clearly explain when a URL cannot be accessed.

3. AI Chatbot: Provide an interactive workplace assistant for writing, planning, research, problem-solving, and productivity questions.



Requirements: Responsive mobile and desktop layouts, modern cards, intuitive icons, structured AI prompts, editable outputs, copy and clear buttons, loading states, and helpful error messages. Include a responsible AI disclaimer reminding users to verify results and avoid sharing confidential information.



Technical constraints: No backend, database, authentication, or paid integrations. Use browser-based temporary state. Do not use hardcoded generic answers or pretend simulated responses are AI-generated. Genuine AI responses must use a compatible AI service; if no API is configured, explain this clearly and keep the interface ready for future integration. Never expose secret API keys in frontend code.
